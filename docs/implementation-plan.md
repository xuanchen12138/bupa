## 检查与状态记录

```powershell
cd C:\Project\bupa
pnpm typecheck
pnpm test
pnpm test:personalization-contracts
pnpm build
```

根 `pnpm test` 当前只运行 API 测试。前端 Repository、历史恢复、交互与浏览器检查需要前端提供独立可复现命令；服务端持久层与可控模型替身测试在第二阶段加入 API 测试。真实模型效果另行评估，不能从规则脚本测试推导。

`pnpm test:personalization-contracts` 已作为独立 M0 消费检查提供，尚未加入 `pnpm test` 或 `pnpm check`。新增导出未齐全时会明确失败；当前缺口和实际结果由后端状态文档记录。该门槛只检查核心契约可用性，不代表第一阶段 UI 或第二阶段服务端历史已完成。

多人协作时仅格式化自己修改的文件，完整集成时再执行 `pnpm check` 并区分既有问题与本轮改动。状态文档应写明已实现内容、实际执行的检查、未执行项、失败项和剩余依赖，不把旧“50 项通过”记录复用为本次验收。本次 BE-03 文档校正本身不宣称新增 API、前端交互或真实模型已通过测试。
